# FastAPI Workout Tracker API

RESTful API сервіс для відстеження особистих тренувань. Проєкт фокусується на побудові надійної серверної архітектури з використанням сучасних інструментів Python для веб-розробки.

Головна мета проєкту — реалізація безпечної авторизації, суворої валідації даних та повної ізоляції записів користувачів на рівні бази даних.

## Головні архітектурні рішення

* **Безпечна авторизація (Stateless):** Реєстрація та вхід реалізовані за стандартом OAuth2 (Password Flow) з використанням JWT (JSON Web Tokens). Хешування паролів виконується криптографічним алгоритмом `bcrypt`.
* **Ізоляція даних:** Налаштовано строгу перевірку належності ресурсів. Користувачі мають доступ виключно до власних тренувань завдяки обов'язковій перевірці `owner_id` при кожній CRUD-операції.
* **Валідація та серіалізація:** Строгий контроль вхідних (JSON тіло запиту) та вихідних даних (відповідь сервера) за допомогою моделей `Pydantic`.
* **Автоматична документація:** Інтерактивна Swagger UI документація для тестування ендпоінтів, згенерована "з коробки" інструментами FastAPI.

## Технологічний стек

* **Фреймворк:** Python 3.9+, FastAPI
* **База даних:** SQLite
* **ORM:** SQLAlchemy
* **Валідація даних:** Pydantic
* **Безпека:** Passlib (bcrypt), PyJWT

## Структура проєкту

Проєкт побудовано за модульним принципом для легкого масштабування та підтримки:

```txt
├── alembic/                # Файли міграцій бази даних (Alembic)
├── src/                    # Головна папка з вихідним кодом бекенду
│   ├── routers/
│   │   ├── auth.py         # Маршрути реєстрації та логіну (/register, /login)
│   │   └── workouts.py     # CRUD операції для тренувань з перевіркою токена
│   ├── database.py         # Налаштування підключення до SQLite (engine, SessionLocal)
│   ├── main.py             # Точка входу FastAPI, налаштування CORS
│   ├── models.py           # SQLAlchemy моделі (схеми таблиць бази даних)
│   ├── schemas.py          # Pydantic моделі для валідації запитів/відповідей
│   └── security.py         # Логіка хешування паролів та генерації/декодування JWT
├── .env                    # Змінні середовища (SECRET_KEY, конфіги) — не додається в Git
├── alembic.ini             # Конфігураційний файл утиліти міграцій Alembic
├── app.db                  # Локальний файл бази даних SQLite
├── bot.py                  # Приклад клієнта (Proof of Concept - Telegram Bot)
├── README.md               # Документація проєкту
└── requirements.txt        # Файл із залежностями проєкту
```

## Встановлення та запуск API

### 1. Клонування та налаштування середовища

Створіть віртуальне середовище та встановіть необхідні залежності у Windows CMD:

```bash
python -m venv venv
venv\Scripts\activate
pip install -r requirements.txt
```

### 2. Налаштування змінних середовища

Створіть файл `.env` у корені проєкту та додайте конфігурацію безпеки:

```env
SECRET_KEY=your_super_secret_key_here
ALGORITHM=HS256
ACCESS_TOKEN_EXPIRE_MINUTES=30
```

### 3. Запуск FastAPI Сервера

Запустіть сервер для розробки за допомогою uvicorn:

```bash
uvicorn src.main:app --reload
```

* API буде доступне за адресою: `http://127.0.0.1:8000`
* **Інтерактивна документація (Swagger):** `http://127.0.0.1:8000/docs`

## API Ендпоінти

| Метод | Ендпоінт | Опис | Авторизація |
| ----- | ----- | ----- | ----- |
| `POST` | `/auth/register` | Реєстрація нового користувача | ❌ Відкритий |
| `POST` | `/auth/login` | Отримання JWT токена | ❌ Відкритий |
| `GET` | `/workouts/` | Отримання списку своїх тренувань | ✅ Bearer Token |
| `POST` | `/workouts/` | Створення нового тренування | ✅ Bearer Token |
| `PATCH` | `/workouts/{id}` | Часткове оновлення тренування | ✅ Bearer Token |
| `DELETE` | `/workouts/{id}` | Видалення тренування | ✅ Bearer Token |

## Приклади тестування через `curl` (Windows CMD)

Усі команди нижче адаптовані для **Windows Command Prompt (CMD)**. Скопіюйте потрібний блок в один клік кнопкою **Copy** і вставте в консоль:

### 1. Реєстрація користувача
```
curl -X POST "http://127.0.0.1:8000/auth/register" -H "Content-Type: application/json" -d "{\"email\": \"user@example.com\", \"password\": \"securepassword123\"}"
```

### 2. Отримання JWT Токена (Логін)
```
curl -X POST "http://127.0.0.1:8000/auth/login" -H "Content-Type: application/x-www-form-urlencoded" -d "username=user@example.com&password=securepassword123"
```
*(Збережіть значення `access_token` із отриманої JSON-відповіді)*

### 3. Створення тренування (Захищений маршрут)
```
curl -X POST "http://127.0.0.1:8000/workouts/" -H "Authorization: Bearer ТВІЙ_ACCESS_TOKEN" -H "Content-Type: application/json" -d "{\"title\": \"Morning Run\", \"description\": \"5km run in the park\", \"duration\": 30}"
```

### 4. Отримання списку тренувань
```
curl -X GET "http://127.0.0.1:8000/workouts/" -H "Authorization: Bearer ТВІЙ_ACCESS_TOKEN"
```

## Демонстраційний клієнт (Telegram Bot)

У проєкті також наявний файл `bot.py`. Він виступає виключно як **демонстрація концепції** клієнтського застосунку. Бот показує, як зовнішні сервіси можуть успішно інтегруватися з даним API, надсилати HTTP-запити (`requests`), обробляти авторизацію та зберігати JWT-токени в пам'яті для виконання захищених маршрутів.
